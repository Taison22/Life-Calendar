# Life Calendar — Календарь жизни

Полноценное desktop-приложение для визуализации жизни в неделях.

## Возможности

- Интерактивная сетка 90×52 (4680 квадратов) — одна неделя = один квадрат
- Цветовая кодировка: прошлое / текущая / будущее / события
- Добавление событий и заметок к любой неделе
- Категории событий (образование, карьера, путешествия и др.)
- Подробная статистика жизни
- Список всех событий с поиском и фильтрами
- Локальное хранение в SQLite
- Экспорт / импорт данных (JSON)
- Тёмная минималистичная тема + боковая навигация

## Тре coбования

- Python 3.10 или новее
- customtkinter
- tkinter (обычно входит в стандартную установку Python)

## Установка и запуск на Windows 10/11

1. Установите Python с официального сайта:  
   https://www.python.org/downloads/  
   **Важно:** при установке отметьте галочку **«Add python.exe to PATH»**.

2. Откройте PowerShell или Командную строку и перейдите в папку проекта:
   ```powershell
   cd путь\к\life-calendar-py
   ```

3. Установите зависимость:
   ```powershell
   pip install customtkinter
   ```

4. Запустите приложение:
   ```powershell
   python run.py
   ```

Если команда `python` не находится, попробуйте:
```powershell
py run.py
```

## Запуск на Linux / macOS

```bash
pip install customtkinter
python3 run.py
```

## Первый запуск

При первом запуске появится окно настройки:

- Укажите дату рождения в формате **ГГГГ-ММ-ДД** (например `1990-05-15`)
- Укажите ожидаемую продолжительность жизни (по умолчанию 90)

После этого приложение рассчитает прожитые и оставшиеся недели и отрисует сетку.

База данных `data/life_calendar.db` создаётся **автоматически**.

## Основные функции

| Раздел              | Возможности                                      |
|---------------------|--------------------------------------------------|
| Календарь жизни     | Сетка, подсказки, клик по неделе, добавление событий |
| Статистика          | Возраст, недели, дни, процент, прогресс-бар      |
| События             | Список, поиск, фильтр по категориям, переход к неделе |
| Настройки           | Дата рождения, срок жизни, экспорт/импорт JSON   |

## Примечания

- Все данные хранятся только локально на вашем компьютере.
- Расчёты учитывают високосные годы и точные календарные даты.
- Размер квадратов сетки автоматически подстраивается под размер окна.
- Для создания `.exe` можно использовать PyInstaller:
  ```powershell
  pip install pyinstaller
  pyinstaller --onefile --windowed --name "LifeCalendar" run.py
  ```
  (после сборки exe появится в папке `dist`)
